## What changed

**Compatibility is observed now, not declared**: `requires.kit` and `requires.pluginApi` are gone,
replaced by a top-level `minKit` of `0.8.0` and a derived `uses` block, so this release installs
only into kit 0.8.0 or later.

- The floor is `"minKit": "0.8.0"` — one bare `X.Y.Z`, a sibling of `id`, `version` and `repo`,
  with no ceiling. Kit 0.8.0 is the release that introduced this contract.
- `requires.kit` and `requires.pluginApi` are deleted from the release manifest and from its anchor
  copy. A kit on 0.8.0 or later refuses an install LOUDLY when a manifest still carries either,
  naming the field and its replacement, so there is no silent half-migrated state.
- `requires` keeps `surfaces` and `plugins`, both unchanged and both still empty.
- `uses` is new and top-level: the host entries and symbols this plugin imports — 13 entries, 99
  symbols — which `pnpm plugin add` checks against the kit's surface ledger BEFORE it copies a file.
- **`uses` is DERIVED by tooling and must never be hand-written.** It is a measurement of this
  plugin's own imports, so `pnpm plugin export` regenerates it whenever those imports change.
- Nothing about what analytics DOES changed: no schema change, no route change, no cube change, no
  UI change, no CLI change. This release is the manifest and the notes beside it.
- The reasoning belongs to the kit rather than to this plugin: see its `docs/CONCEPTS.md` §16,
  decision 5c, for why a prediction was replaced by a measurement.

## How to apply

1. Upgrade the host app's kit to 0.8.0 or later first. An earlier kit reads neither `minKit` nor
   `uses`, and analytics 3.0.0 cannot be installed into it.
2. Run `pnpm plugin upgrade analytics` in the host app, which replays this repository's translated
   diff into the installed copy and records the new surface.
3. Run `pnpm db:generate` in the host app and confirm it emits no migration — analytics 3.0.0
   changes no table.
4. Never hand-edit `uses` in `apps/web/src/plugins/analytics/plugin.json`; regenerate it with
   `pnpm plugin export` if this plugin's imports ever change.

## Conflicts to expect

`apps/web/src/plugins/analytics/plugin.json` → `requires.kit` and `requires.pluginApi` removed,
`minKit` and `uses` added → take this release's version of that file whole. Both new fields are
derived or fixed data, not a local decision, and a merged hybrid of the two shapes installs nowhere.

4. `pnpm lint && pnpm typecheck && pnpm test && pnpm build` is green in the host app.
